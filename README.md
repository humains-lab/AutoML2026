# Explaining the contribution of preprocessing sequences in AutoML pipelines
This repository contains additional material for the paper "Explaining the contribution of preprocessing sequences in AutoML pipelines", presented at [International Conference on Automated Machine Learning 2026 (AutoML 26)](https://2026.automl.cc/)

## Organisation

This repository is organised as follows:
- The `code/` folder contains the Python code implementing the PECA methodology. It includes the `runner.py` and `main.py` files used to execute the experiments, as well as the modifications required for PipeGenie (see the Installation and usage section).
- The `data/` folder contains the train and test ARFF files for each dataset used in the experiments.
- The `results/` folder contains:
    - the raw results generated by the scripts in the `code/` folder,
    - the processed results together with the scripts used to generate them,
    - and the generated images (e.g., boxplots and heatmaps) together with the corresponding scripts.

## Installation and usage

Before executing the experimentation, the `PipeGenie` [repository](https://github.com/PipeGenie/PipeGenie) must be downloaded and modified by applying the changes included in `code/pipegenie/`

Once downloaded:
- `code/pipegenie/xai/` must be added as a new module to the PipeGenie package. It is a new module that must be added to the main package folder `repository_root/pipegenie/`. 
- The modifications contained in:
    - `code/pipegenie/_classification_regression.py` contains modifications to an existing method from the original file and the necesary imports.
    - `code/pipegenie/_individuals.py` contains a new method and modifications to an existing method from to the `Individual()` class in the original file and the necesary imports, located in `evolutionary/` folder.
    - `code/pipegenie/base.py` adds two new methods to the `BasePipegenie()` class and modify its `__init__` method in the original file and the necesary imports.

Each of this files contains a comment to inform if you need to modify or add the method

To use `PipeGenie` with these modifications, you can install it via `pip`:

```bash
$ python -m venv ./venv
$ source venv/bin/activate
$ pip install <pipegenie_repository_root_path>
```

After installation, the `code/runner.py` cript can be executed to run the complete experiment using all datasets contained in the `data/` folder:

```bash
$ pip install -r requirements.txt
$ python code/runner.py
```

This would create the `results/raw_results/` folder together with all required subfolders for each dataset, replicating the repository structure. To run a shorter experiment:
- remove any number of datasets from the `data/` folder, or 
- reduce the number of seeds in the script file. 

Similarly, to generate the processed results, execute the corresponding script from its folder:

```bash
$ python results/processed_results/scripts/result_processing.py
```
Finally, once the processed results are saved, the images can be created

```bash
$ python results/images/scripts/heatmap_builder.py
$ python results/images/scripts/boxplot_builder.py
```
